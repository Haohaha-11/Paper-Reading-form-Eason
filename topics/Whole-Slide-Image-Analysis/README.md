# Whole Slide Image Analysis

这个 topic 关注全切片病理图像分析：核心问题不是"把 WSI 压缩成 token 后分类"，而是让模型像病理学家一样在组织级上下文中进行空间感知推理，从 gigapixel 图像中定位关键区域并建立诊断逻辑。

## 统一阅读问题

- **Q1: WSI 分析与传统病理图像分类的本质差异是什么？**
  A: WSI 需要在 gigapixel 尺度上做空间搜索和证据聚合，而非对单一 patch 分类。诊断依赖多区域、多尺度的空间关系。

- **Q2: 病理学家的诊断过程中哪些步骤最值得被模型学习？**
  A: 低倍镜扫描定位可疑区域 → 高倍镜细看细胞形态 → 跨区域对比和排除 → 证据到诊断的逻辑链。
