# Repository README Redesign

## 目标

将根 README 重构为“个人研究主页 + 可检索文献知识库”首页，并将现有 SVG Banner 升级为带卡通阅读机器人的专业研究风插画。

## 信息架构

1. Banner、双语标题、仓库定位与规模徽章。
2. 仓库用途、个人阅读理念与批读工作流。
3. 精选研究主线与最近更新。
4. 按研究领域分组的完整 topic 索引，包含论文数量、研究问题与入口。
5. 单篇批读结构、质量标准与仓库目录约定。

根 README 不再展开每个 topic 的全部论文表格；详细论文索引继续由 topic README 承载，确保首页清晰且入口完整。

## Banner 设计

- 保留 1200×260 SVG 与深蓝—青色渐变。
- 左侧为标题、副标题和方法标签。
- 右侧加入两个卡通机器人：阅读机器人持论文，图谱机器人连接研究节点。
- 使用 SVG 原生图形与系统字体，避免外部字体和位图依赖。

## 验证

- SVG 可被 XML 解析，viewBox 与尺寸保持一致。
- README 中全部本地链接可解析，18 个 topic 均有入口。
- 仓库统计与当前文件系统一致。
- Markdown 无尾随空格、绝对路径或失效图片。
